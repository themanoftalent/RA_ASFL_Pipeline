# Reliability-Aware Adaptive Split Federated Learning (RA-ASFL)

RA-ASFL studies collaborative ECG classification across clients with different signal distributions, computational capacities, and communication conditions. The repository provides a Python simulation with client-specific cut selection, ECG signal-quality weighting, predictive uncertainty, reliability-aware aggregation, and local adaptation.

The implementation is intended for research experiments on MIT-BIH and PTB-XL. Training, validation, testing, and analysis use locally installed datasets. No ECG waveforms, processed patient records, or generated measurements are stored in this repository.

## Data sources

Use the original datasets from PhysioNet:

- MIT-BIH Arrhythmia Database: https://physionet.org/content/mitdb/1.0.0/
- PTB-XL: https://physionet.org/content/ptb-xl/1.0.3/

Place the MIT-BIH files under `data/mitdb/` and PTB-XL v1.0.3 under `data/ptb-xl/1.0.3/`. Raw and processed datasets remain outside version control. The software will raise an error if required files are absent. The MIT-BIH dataset does not provide a complete subject identifier map for every record; the current loader uses a recording-level proxy and groups records 201 and 202 together. A verified participant map is needed before establishing complete subject separation.

## Set up

Python 3.10 or later is required.

```bash
python -m pip install -r requirements.txt
python -m pytest -q
```

## Run an experiment

```bash
python run.py --config configs/mitbih.yaml --out results/mitbih/ra_asfl
python run.py --config configs/ptbxl.yaml --out results/ptbxl/ra_asfl
```

Compare implemented learning strategies using identical seeds and data partitions:

```bash
python -m scripts.experiment_matrix --config configs/mitbih.yaml --out results/comparison/mitbih
python -m scripts.experiment_matrix --config configs/ptbxl.yaml --out results/comparison/ptbxl
python -m scripts.summarize results/comparison/mitbih --metric macro_f1
```

The training process saves `results.json`, `history.json`, and `checkpoint.pt` inside each run directory. The outputs contain measurements generated by the run, experimental settings, client assignments derived from the seed, validation-selection information, and test metrics. No example performance values are included in the code. A short software check is available through `python run.py --config configs/mitbih.yaml --out results/smoke --smoke`; its synthetic signals are not ECG evidence.

## Implementation

| Module | Function |
| --- | --- |
| `ra_asfl/data.py` | Loading ECG records, group-level partitions, client assignment |
| `ra_asfl/model.py` | Temporal convolutional backbone with five partition boundaries |
| `ra_asfl/quality.py` | Signal-quality descriptors and weighting |
| `ra_asfl/controller.py` | Simulated resource constraints and cut selection |
| `ra_asfl/reliability.py` | JS divergence, MMD helper, uncertainty, reliability and weights |
| `ra_asfl/train.py` | Split forward/backward training, client replicas, aggregation, local adaptation |
| `ra_asfl/privacy.py` | Inversion and membership-inference analysis utilities |
| `ra_asfl/analysis.py` | Paired comparisons and factorial contrasts |
| `scripts/experiment_matrix.py` | Matched-seed baseline experiments |
| `scripts/summarize.py` | Export of recorded results |
| `scripts/validate_runs.py` | Check completion, numerical validity, and matched experiment settings |

## Experimental scope

The executable training modes are RA-ASFL, FedAvg, fixed-cut SplitFed, and a resource-oriented adaptive split strategy. Cut selection runs against simulated device profiles, rather than physical IoMT devices. Intermediate activations and gradients move between logical model components in a single Python process; the implementation does not create secure network endpoints.

Some elements of the mathematical framework remain separate research extensions. In particular, the present loop uses label-level JS divergence for online heterogeneity; the RBF-MMD helper has not yet been connected to a differentiable reference-memory alignment loss. The reliability consistency objective is not optimized as a separate learned-coefficient module. Hardware profiling, complete privacy-attack sweeps, and independently implemented FedProx, FedBN, FedDyn, FedPer, pFedMe, FLEX-SFL, and FedSplitX comparisons require additional modules. These algorithms are not substituted with other implementations under their names.

Consequently, numerical comparisons should be produced by actually executing the corresponding algorithms and checking the resulting artifacts. Do not infer unexecuted ablations, privacy measurements, confidence intervals, or clinical performance. The scripts validate the available experiments but do not certify equivalence to an external experimental run.

## Research integrity and privacy

The benchmark experiments use public ECG datasets and simulated IoMT environments. The software is not a medical device. Keeping raw inputs within logical clients does not ensure privacy against reconstruction, membership inference, or disclosure through gradients and model updates. Conditional mathematical analysis of a Gaussian activation channel must not be interpreted as an end-to-end differential privacy guarantee.

The data remain with their original custodians. Consult the PhysioNet pages above for dataset descriptions, licensing and access conditions.
